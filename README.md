# BURI시뮬레이션

생산·판매 조건을 입력하면 필요자금, 예상 이익, 투입금 회수 시점, 남은 재고를 계산하는 정적 웹 페이지입니다. 빌드·서버·로그인이 필요 없습니다.

## 운영 원칙

- **공개 프로그램에는 실제 사업정보가 없습니다.** 처음 접속하면 모든 조건이 빈칸이며, 기본 조건을 입력하기 전에는 결과를 `—`로 표시합니다.
- **입력값은 각 사용자의 브라우저에만 저장됩니다** (`localStorage`, 키 `buri-sim:v1`). 서버로 보내거나 다른 방문자와 공유하지 않습니다.
- 빈칸(미입력)과 사용자가 입력한 0은 저장·복원·설정 파일에서 모두 구분합니다.
- 저장값을 읽지 못하면 지우거나 덮어쓰지 않고, 자동 저장을 멈춘 뒤 복구·새로 시작을 고르게 합니다. 새로 시작할 때 원본은 `buri-sim:backup:*`에 보관합니다.
- 이전 버전(v1) 저장값은 그대로 읽어 새 형식(v2)으로 변환하고, 원본을 `buri-sim:backup:v1`에 보관합니다. 누락된 항목은 빈칸으로 둡니다.
- ‘예시 체험’은 실제 사업과 무관한 가상 데이터이며 사용자가 고를 때만 적용됩니다.

## 주소 이전 (예: 새 공개 주소로 옮길 때)

브라우저 저장공간은 주소마다 따로이므로 설정 파일로 옮깁니다.

1. 쓰던 주소에서 상단 **내보내기** → 설정 파일(.json)이 기기에 저장됩니다.
2. 새 주소에서 **불러오기** → 그 파일을 선택합니다. 작성 중인 값이 있으면 덮어쓰기 전에 확인합니다.
3. 불러온 조건으로 결과를 다시 계산합니다.

설정 파일에는 입력한 사업정보가 들어 있으므로 저장소·배포 폴더·공개된 곳에 올리지 마세요.

## 실행

- `index.html`을 브라우저로 열거나, 로컬 서버: `python3 -m http.server 8080`

## 구조

| 파일 | 역할 |
|---|---|
| `js/products.js` | 원가 항목 이름 제안, 가상 예시 데이터 (실제 사업정보 없음) |
| `js/calc.js` | 순수 계산 함수 `simulate()`, `requiredSales()` |
| `js/state.js` | 빈 기본값, 저장·복원, 이전 버전 변환, 설정 파일 검증 |
| `js/app.js` | 화면 연결 |
| `js/navigation.js` | 화면 전환 (해시 라우팅) |
| `css/*.css` | 스타일 |
| `tests/calc.test.js` | 계산·저장 단위 검증 (`npm test`, 가상 데이터) |
| `tests/e2e/check.js` | 브라우저 검증 (`npm run test:e2e`, Playwright 필요, 가상 데이터) |

## 계산 가정

- 초기 생산 1회, 추가 생산 없음. 생산비·초기 일회성 비용은 시작 시 전액 지급
- 판매대금은 판매한 달에 전액 수령. 반품·폐기·외상 정산 제외
- 월별 판매량은 남은 재고를 넘지 않음. 남은 재고는 현금으로 환산하지 않음
- 금액은 공급가액 기준, 세금 계산 제외
